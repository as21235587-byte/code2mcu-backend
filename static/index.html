📖 Example commands

Pick one to load it into the prompt box and jump straight to Generate.

Blink LED
Blink the LED on pin 13 with a 1 second delay.

Read Temperature
Read temperature from an LM35 sensor on pin A0.
🔄
Control Servo Motor
Sweep a servo motor connected to pin 9.
🔘
Read Button
Read the state of a push button on pin 7.
🌈
RGB LED Fade

Ultrasonic Distance
Measure distance with an HC-SR04 sensor on pins 6 and 7.

Buzzer Alarm

Motion Sensor
